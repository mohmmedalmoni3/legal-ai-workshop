# نموذج تسجيل ورشة الذكاء الاصطناعي في القانون

واجهة RTL احترافية موجهة لورشة: «كيفية إدخال واستخدام الذكاء الاصطناعي في القانون (بشكل خاص المحاماة)».

## التشغيل
1. ثبّت Node.js 20+.
2. نفّذ `npm install`.
3. انسخ `.env.example` إلى `.env` وضع رابط MongoDB Atlas.
4. نفّذ `npm start`.
5. افتح `http://localhost:3000`.

لإعداد MongoDB Atlas من البداية اتبع ملف [MONGODB_SETUP.md](MONGODB_SETUP.md).

للنشر على Render ومشاركة رابط التسجيل اتبع ملف [DEPLOY_RENDER.md](DEPLOY_RENDER.md).

## متغيرات البيئة
- `MONGODB_URI`: رابط الاتصال من MongoDB Atlas.
- `WORKSHOP_ID`: معرف الورشة، ويُستخدم لمنع تكرار البريد داخل نفس الورشة.
- `WORKSHOP_TITLE`: عنوان الورشة المعروض من الـ API.
- `WORKSHOP_CAPACITY`: عدد المقاعد المتاحة.
- `CORS_ORIGIN`: رابط الواجهة بعد النشر. اتركه فارغًا أثناء التطوير المحلي.
- `ADMIN_USERNAME`: اسم مستخدم لوحة الإدارة.
- `ADMIN_PASSWORD`: كلمة مرور لوحة الإدارة.
- `ADMIN_SECRET`: مفتاح طويل عشوائي لتوقيع جلسة الإدارة.

## فحص سريع
- `GET /api/health` للتأكد أن الخادم يعمل.
- `GET /api/workshop` لعرض بيانات المقاعد.
- `POST /api/register` لإرسال تسجيل جديد.
- `/admin.html` للدخول إلى لوحة الإدارة بعد ضبط متغيرات الإدارة.

## ما تم بناؤه
- تصميم Responsive RTL بطابع قانوني وتقني.
- نموذج تسجيل يعمل فعليًا.
- MongoDB Atlas لتخزين التسجيلات.
- منع تكرار البريد الإلكتروني داخل نفس الورشة عبر unique compound index.
- حد أقصى للمقاعد يتحقق من الـ Backend.
- Rate limiting وحماية Helmet.
- صفحة تعرض المقاعد المتبقية.
- مكان جاهز لاستبدال الشعار لاحقًا.

## ملاحظة
هذا الإصدار هو أساس المشروع. يمكن لاحقًا إضافة بيانات الورشة الفعلية، شعار الجهة، QR للتسجيل، بريد تأكيد، لوحة إدارة، CAPTCHA، وشروط الخصوصية النهائية.
